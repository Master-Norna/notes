# tomlkit #612 修前/修后对照复现

同一个操作（给已有的字符串值追加一段文本），分别喂给两个 tomlkit 源码快照：

- `tomlkit_before/`：父提交 `79039653cbe5ff2a2e23042717455a2ac4875539`（修复前）
- `tomlkit_after/`：合并提交 `61941deb3c7155e88d5f038148b33a599c04a530`（修复后）

两份快照的 `__init__.py` 都写着 `0.15.1`（发版号尚未 bump），因此版本一律以 git SHA 标识。

## 怎么跑

```bash
python run.py          # 完整对照报告
python run.py --test   # 断言自测，全部通过时退出码 0
```

- Python >= 3.9，零第三方依赖，完全离线。
- 脚本会把 `tomlkit_before/`、`tomlkit_after/` 先后插到 `sys.path` 最前并核验
  `tomlkit.__file__` 确实落在快照目录里——若解释器环境里装有同名 tomlkit 会直接报错，
  不会静默地拿错版本。

## 各用例看什么

| 用例 | 修复前 | 修复后 |
| --- | --- | --- |
| 主反例：`item("foo")` 追加 `"` | 值对，序列化成 `"foo""`，读不回 | 序列化成 `"foo\""`，读回 `'foo"'` |
| 追加 `\` | `"foo\"`（闭引号被吃掉），读不回 | `"foo\\"`，读回 `'foo\'` |
| 追加换行 | 引号里裸换行，读不回 | `"foo\n"`，读回 `'foo\n'` |
| 对照A：右侧本来就是 String | `"foo\""`，读得回（#235 修过的路径，保持不变） | 同左 |
| 对照B：追加普通文本 | `"foo bar"`，两版一致 | 同左 |
| 边界：字面串 `'foo'` 追加 `'` | 输出 `'foo''`，读不回 | 同左（字面串无转义机制，修复不覆盖；构造路径 `from_raw` 才会拒绝） |
